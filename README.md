# Housing Affordability in Wales

This project explores housing affordability trends across Wales, focusing on the impact of second-home ownership and regional price differences.

## Objectives
- Analyse house price data from the ONS and Land Registry.
- Compare affordability ratios across Welsh regions.
- Visualise trends using Python (pandas, matplotlib).

## Data Sources
- Office for National Statistics (ONS)
- HM Land Registry
- Local authority housing reports

## Methods
- Data cleaning and analysis in Python.
- Graphs and regression models to identify patterns.
- Policy discussion based on findings.
